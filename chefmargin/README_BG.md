# ChefMargin v1.0 — Android + Windows

Самостоятелна офлайн програма за изчисляване на ресторантска себестойност, инспирирана от работния процес на „Кухненски гард“ (не е копие на оригиналните му файлове, защото не са достъпни в този проект).

## Какво е направено

- **28 езика** в избора на език, български по подразбиране. Превключване на основната навигация, формулярите, предупрежденията, статуса и настройките на всички 28 езика; примерните имена на ястия и продукти остават на английски.
- Режими ден/нощ, оформления за телефон и лаптоп.
- Продукти с количество в опаковка, цена, добив след обработка, доставчик и единица.
- Рецепти с грамажи, порции, ДДС, друг пряк разход и целева себестойност.
- Автоматични формули и променящ се резултат при промяна на доставна цена.
- Меню, предупреждения за висока себестойност, справки и CSV.
- Снимки към рецептите, JSON архив/възстановяване (включва снимки); локално съхранение.
- Без облачен акаунт, без платен сървър, без мрежова връзка.

## Използване

Отворете `web/index.html` в браузър за преглед. **Важен детайл:** за някои браузъри достъпът до локални файлове може да е ограничен; затова готовият APK/EXE използва собствени контейнери.

**Windows**: преносим `.exe`, който стартира без инсталатор, се компилира с `npm install && npm run build:win` на Windows 10/11. Този архив е изходен код, а не готов EXE.

**Android**: от папка `android` командата `gradle assembleDebug` с JDK 17 и Android SDK 35 прави `app-debug.apk`. APK се инсталира еднократно на телефона — Android не може да изпълнява APK без инсталиране.

В GitHub Actions има сборка на двете версии. Не е гарантирано, че билдовете ще минат без корекции на CI; проверете резултата от Actions.

## Формули

- `unit_cost = pack_price / (pack_quantity × usable_yield_fraction)`
- `batch_cost = SUM(qty × unit_cost) + other_batch_cost`
- `portion_cost = batch_cost / number_of_servings`
- `suggested_gross = portion_cost / target_food_cost_fraction × (1 + VAT_fraction)`
- `contribution = actual_selling_gross / (1 + VAT_fraction) - portion_cost`
- Сумите са **само преки разходи за продукти и зададени допълнителни разходи**; не са нетна печалба. Данъчните ставки са демо настройки.

## Важни бележки

- Всички данни остават **само на текущото устройство**. За прехвърляне между телефон и лаптоп използвайте архив → възстановяване.
- Изборът на валута **не конвертира стойности**. Въведете всички цени в избраната валута.
- Демонстрационните стойности са измислени; не са актуални цени.
- Android APK от `assembleDebug` е тестова инсталация. За публична продажба са нужни стабилно подписване, проверки и release билдове.
- Windows EXE не включва инсталатор, но размерът му ще е по-голям, защото съдържа графичната среда Electron.

## Версия 1.0.1 — превод на примерните продукти
- Всички 14 примерни продукта и 3 примерни рецепти се показват на избрания от 28-те езика, включително български.
- Старите английски примерни имена също се превеждат при показване; данните и формулите не се изтриват.
- Добавените от потребителя продукти и преименуваните рецепти се запазват без автоматичен превод.
- На Android тестовите APK файлове от различни GitHub компилации може да имат различен debug подпис: преди преинсталиране създайте архив на старите данни в Настройки → Запази архив.

## Версия 1.1 — Интернет проверка на цени
- Нов раздел „Онлайн цени“: филтър по рецепта и продукт.
- Бутон за онлайн справка към сайта на КЗП, МЕТРО, Kaufland, Lidl и eBag (за BG) или уеб търсене при друг език.
- След ръчна проверка на разфасовката, цена и валута потребителят *потвърждава* стойността; себестойността на всички рецепти се преизчислява веднага.
- Пазят се източникът, часът на проверка, URL и кратка история на цените в локалния архив.
- **Важно:** това е функция за онлайн проучване и ръчно потвърждаване, **НЕ автоматично извличане на цени**. Не показвайте примерните стойности като актуални магазинни цени.
- За истинско автоматично обновяване от официални данни ще е нужен отделен ценови източник/сървър, съгласуване на валута, разфасовка и местоположение и проверка на лицензните условия.

## Версия 1.2 — автоматично ценообразуване от интернет
- НОВ раздел **Онлайн цени**: бутон „Изтегли актуалните цени“, без ръчно попълване на покупни цени.
- България / EUR: публични архиви на КЗП от https://kolkostruva.bg/opendata; сравнение по магазини, разфасовки, min/median/max.
- Данните се събират от GitHub Actions всеки ден и се публикуват в отделния клон `chefmargin-prices` като `chefmargin-data/prices.json`.
- За налични съпоставими продукти след натискане на бутона автоматично се заменя примерната цена. При липса на съвпадение или интернет **предишната стойност остава**, но не се нарича текуща цена.
- Ресторантските/договорните доставни цени, персонални намаления, промоции и регионални различия **не са гарантирани**. При липса на публични данни приложението го показва.
- Версията не обещава онлайн цени за всички 28 държави: за останалите езици интерфейсът е локализиран, но текущият ценови източник е български.
- За Android: INTRNET разрешение (само публичния GitHub JSON feed) и Android native HTTP bridge, без опасно разрешаване на универсален file:// достъп.
