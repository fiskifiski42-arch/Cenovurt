# Ценовърт

Уеб приложение за следене на цени, с три безплатни наблюдения, ежедневна проверка, ръчна проверка и email известие, когато цената достигне зададения праг.

## Локални тестове
Нужен е Node.js 20+. Стартирай `node --test`. GitHub Actions автоматично изпълнява тестовете при всеки push.

## Вход
Потребителят въвежда имейл, получава еднократен шестцифрен код (валиден 10 минути) и след потвърждение получава сесия за 7 дни. Всички операции с наблюдения и плащания изискват потвърдена сесия. Не пазете истински секретни ключове в GitHub.

## Нужни Vercel Environment Variables
- `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` – база за наблюдения и еднократни кодове.
- `RESEND_API_KEY` и `RESEND_FROM` – изпращане на кодове и сигнали. За реални клиенти е нужен потвърден домейн в Resend.
- `CRON_SECRET` – защитата на ежедневния cron, минимум 20 символа.
- `AUTH_SECRET` – препоръчителен отделен секрет, минимум 20 символа; при липса се използва `CRON_SECRET`.
- `STRIPE_SECRET_KEY` – само ако плащанията са активирани.
- `APP_URL` – каноничният публичен URL, по подразбиране Vercel адресът.

Провери Vercel Deployment и направи жив тест на кода за вход, създаване на наблюдение, ръчна проверка, email сигнал и платежен поток, преди публично представяне.

## Ограничения
- Vercel Hobby изпълнява cron най-много веднъж дневно по UTC.
- Не всяка магазинна страница позволява автоматично изчитане. Anti-bot/HTTP 403, JavaScript-rendered price и нетипичен HTML могат да изискват специална интеграция.
- При цена на страницата в BGN тя се преобразува в EUR по фиксиран курс 1 EUR = 1.95583 BGN.
- Проверени са кодът и автоматизираните тестове. Реални Stripe плащания, произволни магазини и email доставяемост изискват отделен жив тест.
